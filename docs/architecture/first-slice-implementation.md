# 首个前端切片实现说明

## 已实现

- 新增 `services/course.js`，统一课程列表、分类和详情访问。
- 保留现有后端接口优先策略；请求失败时回退到本地课程样本。
- 本地回退由 `config.js` 的 `enableLocalSampleFallback` 控制，发布前必须关闭。
- 课程详情加载时补充课程目录数据。
- 新增“关联词汇”标签页，展示样本词汇的单词、词性和释义。
- 增加 `navigateToVideo`，修复“继续学习”没有处理函数的问题。
- 修复目录首节试看判断使用未定义 `idx` 的问题，改用明确的章节/视频索引。

## 当前限制

- 本地样本视频没有可访问 URL，只能验证目录和播放器入口；真实试听需要确认媒体服务地址。
- 真实后端课程与本地教材之间尚未建立 ID 映射，因此真实课程暂不自动展示教材词汇。
- 购买逻辑仍未修改，当前切片不包含支付和订阅。

## 人工验收

在微信开发者工具导入 `D:\project\learn` 后检查：

1. 后端不可用时，首页能显示本地样本课程。
2. 点击样本课程进入详情，详情、目录、关联词汇三个标签可切换。
3. 目录首节显示“试看”，其余内容不误标试看。
4. 后端可用时，课程列表和详情仍优先使用接口响应。
5. 真实课程详情加载失败时，不出现白屏，并给出可理解的空状态或样本回退。

该切片只验证内容组织和页面逻辑，不代表生产 API 或媒体服务已经确定。
