# 内容与媒体资产盘点

## 教材与词汇

本地 `ruflo_content` 中已确认：

- `n_study_book`：31 本教材，包含教材名、封面相对路径、词数、类型、价格和介绍字段。
- `n_study_book_word`：63,783 条教材词汇，覆盖 31 个教材名，15,370 个去重单词。
- 历史明细行统计曾显示教材词汇与俄语主索引 `x_7500km_russian_index_new_test` 精确匹配约 98.4%，该数字不可与去重词条直接比较；当前 `profile_content_exports.py` 的去重后 casefold 直接命中率为 88.4323%，内容映射报告在更严格的规范化词条集合上加入大小写/重音/词形三级适配后的覆盖率为 91.0858%，分别见 `docs/phase0/content-quality-report.json` 和 `docs/phase0/book-dictionary-comparison.json`。
- 教材词汇自身包含释义、例句、词性、重音、搭配和部分词形数据，可先直接用于课程关联词汇展示。
- 主索引有 166,260 条，适合作为通用词典检索基础；`e_change_word` 适合作为后续词形详情来源。

## 媒体资产

- `weixin/media/video/` 有 6 个 MP4，约 1.68 GB，适合本地试听页面验证，但当前证据不足以证明它们是生产课程视频。
- `7500km-android` 有少量字母发音 MP3 和资源音频，主要用于客户端演示或基础发音，不等同于完整课程音频库。
- 教材表的封面字段是旧服务器相对路径，例如 `/book/...png`；对应图片文件未随本轮数据库内容导出，需要单独盘点或由后端提供。
- 当前 `learn/images/` 只有小程序 UI 图片，没有课程视频、课程音频或教材封面资产。

## 首个切片建议

建议先选两本样本：

- `id=1`：东方教材大学俄语3，1,247 个词，适合作为常规教材流程样本。
- `id=13`：俄语专业大纲综合，7,836 个词，适合作为大数据量和检索性能样本。

直接使用本地教材元数据和教材词汇生成课程详情/词汇列表；视频暂用 `weixin/media/video/` 做本地 UI 验证，后续再确认真实媒体授权、URL、封面和生产存储位置。

已生成本地页面验证样本：`data/content_samples/books.json`、`book_1_words.json` 和 `book_13_words.json`。样本只包含课程展示和词汇展示所需字段，不包含用户数据。

## 数据风险

终端显示俄语/中文存在编码显示异常，但数据库读取出的 Unicode 码点正常；导入文件和表行数已校验，不应据此重新导出。
