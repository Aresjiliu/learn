# Version3：学习者体验与生产就绪改进方案

日期：2026-10-19。状态：用户已确认“统一视觉基线＋可靠视频学习”作为下一实施批次；其余为后续路线，不是已实现清单或发布批准。

本文细化既有 G0–G7 路线，不另起框架或重复建设后端。沿用原生 JS、Vant 1.11.7、现有内容适配层与已批准的轻量词典、课程内按需词汇学习。保持远程写入关闭，生产库只读。

## 1. 判断：当前是可运行的开发验证版

已查看 `ui/version3/屏幕截图 2026-10-19 151628.png`。页面已经具备细边框、课程分割线、图标和局部浅底色，缺质感的根因不是单纯缺装饰：

- **主次弱**：三个同权重入口先于续学；“返回上次学习内容”不能让用户判断具体课程、章节和位置。
- **层次单一**：白背景、白卡片和白列表主要靠细线区分；多个矩形边框竞争注意力。不可通过给每块都加阴影解决。
- **字体表现不一致**：截图中文正文有明显衬线观感，俄文与中文风格割裂。源码虽声明系统无衬线字体，仍需实际渲染核验，不能只换一次字体字符串就宣布修好。
- **跨页割裂**：全局 token 为蓝色，首页/词典局部珊瑚红；底栏仍蓝色，视频/练习/个人页尚未统一。
- **内容仍为样本**：单条课程、通用封面、“免费演示”和工程说明无法证明真实商品组织能力。留白不应靠广告、假课程或假学习统计填满。

### 实际代码缺口索引

| 位置 | 当前事实 | 产品/发布影响 |
|---|---|---|
| `app.json`、`styles/design-tokens.wxss`、各页WXSS | 蓝色全局与局部珊瑚红同时存在 | 跨页像不同产品，需有计划统一 |
| `pages/course/video/video.js`、`components/media-player` | 只有速率状态/事件，无选择与调用；切集先换当前视频 | 倍速不可用，进度/延迟事件存在串片风险 |
| `services/playback-progress.js` | videoId单键、同步读写无失败保护 | 身份契约、迁移和异常策略不足 |
| `pages/exam/practice/practice.js` | 单试卷会话恢复旧correct，重练覆盖；同步写后才反馈 | 答案更新失效、历史保存与异常容错不足 |
| `services/content-api.js`、`pages/orders/orders.js` | 内容响应固定hasPurchased=false；订单占位 | 接内容服务不等于接通权益与交易 |
| `pages/profile`、`pages/my-courses`、`pages/settings` | 旧登录流程、本地入口受登录限制、GET受写开关限制、设置占位 | 游客体验和正式账号能力均需补齐 |
| `utils/request.js` | 任意401清除登录，未区分skipAuth公共请求 | 公共内容故障可能误触发退出登录 |
| `services/wordbook.js` | 有受保护存储核心，无页面调用 | 能复用逻辑，但学习者尚无法保存/复习 |
| `config.js`、`services/content-api.js` | 本地HTTP/样本模式；关闭内容API直接回本地试卷 | 需发布配置门禁，正式包不能静默返回样本 |

主代理已复核独立审计的上述关键路径；风险不能只通过改文案或打开总开关解决。

### 可选路径

1. **推荐：统一轻学习设计系统 + 按学习闭环交付。** 保留既有页面/路由，统一基础视觉与状态，优先播放器、续学、词本；商业化独立设计。成本可控且能减少反复返工。
2. 仅首页精修：成本最低，但不能解决跨页风格、学习记录与成交后的履约问题，只能作短期局部修补。
3. 整套商城/学习平台替换：看似功能齐全，但会引入账号、词典身份、教材映射、媒体和旧资产迁移成本；当前不推荐。

## 2. 从用户任务出发，而非从页面数量出发

以下是依据现有资产提出的需求假设，不冒称已完成用户访谈。首发面向教材自学和俄语考级人群；后续用少量真实学习者走查验证。

| 用户当下的问题 | 必须提供的能力 | 不能用来替代它的东西 |
|---|---|---|
| 第一次来，不知道该学什么 | 清楚的课程适用对象、教材版本、范围、试听入口、可用内容状态 | 大幅广告、空泛口号、虚构热门销量 |
| 昨天学到哪里 | 具体课程/章节/播放位置、最近学习记录、一键继续 | 只有“继续学习”标题或孤立秒数 |
| 语速快/复习赶时间 | 减速/倍速、回退重听、选集、全屏与可恢复播放 | 只有原生播放按钮 |
| 查到词后过两天忘记 | 听音、稳定身份保存、生词本、到期复习、删除与离线摘要 | 按钮看似收藏成功但无可靠存储 |
| 做题后不知道弱项 | 正确答案、解析有无说明、错题重做、可靠成绩记录 | 保存旧 correct 值一直沿用 |
| 付了款担心看不了 | 明确商品范围/有效期、订单状态、权益恢复、客服与退款路径 | 前端支付回调即显示已购 |
| 暂时不想登录 | 查词、试听、本地词本/记录和设置仍可用 | 将所有入口都挡在登录后 |

首发主链路：发现课程 → 试听/判断适合程度 → 获得有效权益 → 视频/配套词汇学习 → 查词保存 → 练习/复习 → 下次继续。购买与已拥有内容恢复分别验收。

## 3. UI：质感来自统一层次，不来自堆装饰

### 3.1 视觉系统候选值

在现有 `styles/design-tokens.wxss` 收敛语义 token，逐页迁移，不能只把蓝色全局替成红色：

- 背景：浅暖灰 `#F7F7F5`；阅读/内容面板白色；珊瑚红仅承担主要操作与选中态。长释义正文区域保持白底。
- 文字：主文字 `#232326`，次文字 `#67676F`，弱提示另设 token；错误/成功/锁定独立语义，不把品牌红兼作全部状态色。
- 层次：每屏优先一个主行动；重点续学面板有轻微色阶，普通列表用分割线，工具入口弱化外框。仅浮层等确需抬升时使用轻阴影。
- 间距：8rpx 基础节奏；页面边距32rpx；标题/正文/辅助文字有明确层级，正文建议28–30rpx起，长俄文可换行。触摸目标至少88rpx。
- 圆角：面板16rpx、控件12rpx作为候选，避免每页自定一套；原生导航与底栏颜色/图标粗细统一。
- 字体：检查实际命中字形、组件隔离和开发者工具字体环境；在 iPhone 与 Android 验证中文、西里尔字母、ё/й与组合重音。暂不下载庞大中文字体包掩盖问题。
- 图像：真实、可信、统一比例的课程封面；没有封面使用真实标题的中性模板。可有少量无文字装饰，但不在查词/答题正文后铺背景图，不新增无业务价值轮播。

### 3.2 首页和页面家族

- **首页**：已有记录时，课程名 + 章节名 + “学至 mm:ss”成为首要续学面板；无记录时显示真实入门/试听内容。快捷工具随后，课程列表明确教材、适用水平、实际章节和试听状态。没有可信时长/完成数据则不画百分比。
- **课程详情**：简介、适用对象、学习范围、试听/继续、章节状态；配套词汇仍按需进入独立页。真实商品数据接通前，不把样本价格当可购买报价。
- **播放器**：播放器下方固定可达的倍速/重听/目录工具；当前选集与保存状态清晰，自动下一节可关闭；选项失败有反馈，不只变更标签。
- **词典/词本**：列表紧凑、详情分区；读音和保存是主要动作，完整原文保持可达；复习入口只显示真实记录。
- **练习**：题干/听力/选项/提交主次明确；判错后能查看解析或明确“暂无解析”，完成页进入真实错题记录。
- **我的**：学习记录、词本、我的课程、订单、帮助。游客也能进入本地功能；登录只在需要远端身份的操作前触发。无需本轮新增顶级 Tab。

复用现有 Vant Search/Icon/Loading；ActionSheet/Popup/Cell/Button 等仅在确认具体交互后按需纳入离线构建闭包，核验锁定版本 API、字体、许可证与包体。不安装第二套完整库，也不机械封装每个控件。

## 4. 必需功能及验收

### 4.1 视频学习：下一实施切片

源码 `components/media-player` 只透传事件，视频页只有 `playbackRate` 状态；没有用户选择入口或 VideoContext 倍速调用，故不是“已实现只是没显示”。

建议首版：**0.8×、1×、1.25×、1.5×、2×**，默认1×；选择当前学习偏好后跨选集保留。慢速便于初学听辨，高倍速用于复习；3×/4×不纳入首版。

- 在组件作用域创建原生 VideoContext，组件承接实际速率调用；页面负责用户偏好与展示，不跨组件猜测 video id。
- 兼容能力不支持/调用失败时保留默认速率并说明；不得因标签更新就宣称实际倍速成功。全屏工具可达另行验证。
- 先保存旧视频再切新视频；所有媒体事件绑定播放实例/课程/视频身份，旧事件不能写到新选集。
- 暂停、切集、切后台、退出保存；存储失败不能打断播放，显示“本次进度未保存”并允许重试。
- 补回退10秒、恢复位置提示和下一节开关；重复观看允许回退，不把“最大播放位置”冒充最后观看位置。
- 验收：A→B快切、旧A延迟事件、重试重建、前后台、横竖屏、重新进入、偏好损坏、存储满、iPhone12/13 Pro和Android实际播放。自动化断言与真机听看分开记录。

### 4.2 学习记录：不是一个统计卡片

已有 `playback-progress.js`、`practice-progress.js`，复用并完善，不再建一套平行进度模块。

- 区分最后观看位置、观看覆盖范围、学习完成、有效学习时长；拖到结尾不能直接等价学完，倍速下媒体秒数不能直接当真实投入时长。
- 键至少明确游客/账号、课程、视频、内容版本；确认视频ID全局唯一契约之前，不依赖单videoId隔离全部内容。
- 本轮内存夹具证明同videoId记录最后写入覆盖；这是潜在身份边界风险，不是已经证明生产存在重复ID。同步写入抛错也会直接冒泡，需失败保护。
- 旧v1位置迁移须可回滚；归属不明不自动绑定其他课程或其他用户，旧原始值保留。未知版本只读，损坏不得静默清空。
- 真实学习事件幂等去重；切后台不计时、跨天按明确时区归属，查词一次不自动算“已掌握”。
- 游客本机可用并说明卸载风险；后续登录合并需显式策略，服务端按事件/版本去重，不简单把全部秒数取最大。账号退出不泄漏他人记录。
- 记录页提供最近学习、课程续学、练习结果/错题入口和保存异常；云同步未接时明确“仅保存在本机”。

### 4.3 生词本与复习

已有受保护的v1词本核心和12项测试，但详情按钮、微信存储适配、词本页与调度尚未接入。

- 先接真实保存/移除/数量/重启恢复，独立主词典稳定ID与教材来源键；不以同拼写合并同形词。
- 然后到期复习、忘记/记住反馈、可恢复会话和真实学习记录；借鉴已下载 LingoSnake 的纯调度、会话锁与测试思想，不复制英语数据/整套UI。
- 首发不要求花哨游戏、AI对话或全量离线词典；发音缺失与网络失败有明确状态。

### 4.4 课程购买与履约

当前 `pages/orders/orders.js` 是占位说明；“我的课程”只读GET仍被写开关挡住；内容中的布尔 `hasPurchased` 不足以表达查询失败、有效、过期等状态。

建议先以**单课程/教材课程包一次购买**作为建模候选，不先做自动续费、优惠券、分销、积分商城。具体SKU、有效期、价格与售后需经营决策确认，不能由前端擅定。

- 商品：明确包含哪些课/词汇/练习、试听范围、有效期、售后与可用终端；价格由服务端可信配置决定。
- 订单：待支付、确认中、成功、关闭、退款中、已退款等状态及用户恢复路径；取消不报成功，超时/回调延迟可查单。
- 权益：未查询/查询失败/未拥有/有效/已过期/已撤销分开。前端缓存不是授权；服务端保护课程/媒体，独立短期媒体票据不泄漏账号令牌。
- 支付：通道适用性先核验；服务端签名与回调认证、金额/币种/商品/主体归属校验、重复通知幂等、补偿查单、对账与退款后权益调整，客户端回调不直接发权益。
- 已有App付费记录：先确定是否共享权益及账号绑定/映射契约，不能把设备本地token当跨平台身份，也不自动搬入个人敏感数据。
- 开发期使用独立测试数据与可模拟通道；真实支付能力、主体和商品类目未核实之前不展示有效购买入口，不为了GET查询打开全局远程写入。

**当前政策核验边界**：官方类型库可核实 `wx.requestVirtualPayment` 存在，但本轮官方虚拟支付规则页无法抓取。普通 `wx.requestPayment` 文档不是录播课可直接采用该通道的证明；不引用第三方费率/期限或旧iOS禁令作结论。实施前以当前微信官方规则和该AppID实际开放能力核验通道、终端、退款规则及费用，再核算降价后的净收入。不能设计外链绕过规则。

### 4.5 练习与生产运营

- 答案不可校验的题不进入评分；有答案无解析可练但说明缺失，不用AI生成后直接当权威解析。
- 练习恢复绑定题目/答案版本，不继承同ID旧正确结果；存储写失败不阻塞答题，错题记录与当前会话分离。
- 生产配置必须与演示隔离：HTTPS/合法域名、真实媒体托管、限时鉴权、断网恢复、内容版本发布回滚、脱敏错误监测、备份恢复演练。
- 本地127.0.0.1可播放不证明真机或生产可达。字幕/逐句重听在有可靠字幕与时间轴后再加，不凭转写猜对齐。
- 公共内容401、登录过期、媒体票据过期分别处理；不因公共请求失败清除真实账号。发布环境禁本地URL与隐式样本回退，用自动门禁而非依赖人工记忆。
- 客服/内容纠错/售后入口可达；课程上下架、错误音频/错题隔离、订单与权益排查先做到可运营，复杂管理后台后续按需求扩展。
- 隐私告知、必要身份信息最小化与个人数据删除/记录保留策略单独核验；学习记录也不自动等于可公开数据。

## 5. 交付顺序和退出标准

| 切片 | 内容 | 必须能证明的结果 |
|---|---|---|
| A：统一视觉基线 | token/字体核验、导航/底栏、首页真实续学信息；先做首页与视频工具栏样板 | 同一真实内容在320/375/390宽可读，当前机型安全区/长文/空态/错误态截图，无风格跳变 |
| B：可靠视频学习 | 播放实例隔离、保存异常保护、迁移；随后倍速/重听/偏好 | 切集不串进度、切后台与重启可续播，实际倍速生效，不丢原记录 |
| C：留存闭环 | 词本微信适配/页面、复习、最近学习记录与练习版本保护 | 教材→查词→保存→复习→重启恢复；成绩不串题、不重复统计 |
| D：生产交易 | 商品规则/平台能力确认、账号/订单/权益/媒体服务、支付适配与售后 | 未付不获权、已付可恢复、重复回调不重复发放、退款一致；测试环境全链路 |
| E：发布准备 | 真实内容批次、部署/监控/备份、设备/弱网/无障碍走查 | 无样本价格混入，合法域名开启校验，恢复演练与明确回滚；另行授权发布 |

A与B是下一批，非长期停留首页；C无需等待真实支付资质，D的平台能力核验可旁路提前推进。各切片小规格→失败测试→实现→独立审查→回归→实际界面/设备验收；不将整个宽泛方案一次性当可执行代码任务。

优先级：资金/权益/身份/数据丢失为发布阻断；倍速、续学、词本、可读性为首发必要体验；优惠券、社区、排行榜、炫酷动效、实时AI陪练后置。

业务评估围绕真实数据：试听可播放率、付费后权益恢复成功率、续学恢复成功率、查词后保存/复习完成率、内容纠错量。先建立定义与基线，不虚构转化率目标；仅采集必要且已告知的数据，不将明文学习内容/用户标识写入公共日志。
