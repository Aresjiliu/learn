# 主链路与 UI 分阶段计划（2026-10-18）

## 范围与底线

独立开发优先复用现有原生小程序、`services/` 适配层、只读内容导出与本地媒体服务。课程/题库原始数据及音视频不入 Git；用户个人信息不迁移。`enableRemoteWrites=false` 继续作为默认门禁。自动测试通过不等于模拟器和真机验收。

## P0：让真实内容可用

1. 题库听力：仅将样本中有合法路径、已缓存且通过 MP3 校验的 7 个文件映射给 8 道题；逐题检查播放、切题停止、缺文件降级。本机 HTTP/Range 与静态检查已通过；开发者工具实际解码待验收。
2. 搜词：词典单独使用 `18091` 的完整本地导出索引，不切换课程/题库；俄语精确、前缀、包含、释义结果依次排序，支持俄语 `е/ё`。本机俄语“привет”和中文“你好”接口已返回；页面实测待验收。服务掉线时显示“仅离线样本”，不把样本缺词误报为主词典无词。
3. 所有只读配置、音频清单与搜索行为进入 `check_phase1.ps1`；发布配置不得使用回环地址或关闭域名校验。

## P1：完成可持续使用的学习闭环

按“首页选课→课程目录→视频/课词→高质量练习→错题与继续学习”逐页验收；每页覆盖加载、空、失败、重试与返回状态。先让审核通过的试卷可分页进入练习，禁止缺答案或越界选项的题目流入；不把 279 份候选直接视作上线题。教材词与主词典继续按已审映射合并，未审词形只作候选提示。进度先用本地存储，明确更换设备不迁移；购买/订阅入口在未接支付前不得伪装可购买。

## P2：视觉和交互验收

以 `styles/design-tokens.wxss` 为基线统一间距、字号、色彩、卡片和按钮，先重做首页、课程、练习与词典的真实截图，再扩展到个人中心。验收 320–430px 宽屏、长俄语单词、中文换行、触控尺寸、滚动/安全区及错误态。每轮在微信开发者工具留“页面+操作+截图+工具版本”的记录；用户此前展示的旧 UI 不作为成品标准。

## P3：媒体体验与发布准备

视频倍速（0.75/1/1.25/1.5/2）在 P1 稳定后加入；补齐有来源可核验的发音音频，不为裸文件名显示可播放。AI 仅在内容审校与成本上限之后做可关闭的辅助讲解/例句，不替代标准答案。最后配置 HTTPS 合法域名、内容版本、异常监控、授权/支付与真机测试，再讨论上线。

## 每阶段交付门槛

改动先有失败用例或可复现记录；运行完整阶段检查、检查 Git 文件清单不含原始导出/媒体/凭据，再提交推送。涉及媒体与布局的项必须补开发者工具和真机证据，未验证项保持“待验收”，不写“已修复”。
