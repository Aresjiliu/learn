# 微信开发者工具验收清单

本清单用于区分静态检查和真实运行验收。CLI `open` 已成功加载工程且 `islogin` 返回 `login=true`，但 GUI 编译、页面视觉验收和真机验收仍未完成，以下项目需要在开发者工具中执行。

CLI `auto --project ... --port 11367 --trust-project` 在 AppID 权限阶段失败，输出 `Port is not provided`，没有编译结果。CLI 无独立本地 `compile` 命令；本轮未执行 preview/upload。

## 启动

- 导入 `D:\project\learn`，确认 AppID 与 `project.config.json` 一致。
- 本地开发保持 `project.private.config.json` 的 `urlCheck=false`；发布前恢复合法域名校验。
- 新开终端启动测试媒体：`python scripts/serve_test_media.py --root audio --host 127.0.0.1 --port 18090`；确认本地已有 `videos/video1.mp4` 与 `audio/wordaudio/` 中的缓存 MP3。
- 搜索完整词典需按 [词典服务运行手册](../operations/dictionary-service.md) 启动索引服务（18092），并运行 `scripts/check_indexed_dictionary_http.py`。默认 `enableLocalDictionaryApi=true`，不必开启全局 `enableContentApi`；服务不可达时搜索页明确提示仅查离线样本，已选稳定词条详情失败可重试。
- 执行 `python scripts/check_runtime_config.py`，确认 `enableRemoteWrites=false`、本地地址和音频开关状态符合预期。
- 开发者工具点击“编译”。CLI 的 `open` 只能证明 IDE 接受项目；当前没有独立的本地 `compile` 命令，不能把 `preview` 当作本地编译。

## 主链路

以下均为待人工验收事项；逐项记录结果并附能说明页面状态的截图，不得仅凭自动测试标为通过。

1. 首页：检查搜索、分类切换和快捷入口（课程、练习、词典）的实际跳转；覆盖加载失败重试与无结果状态。
2. 课程详情与视频：检查课程介绍、视频目录和词汇列表；从目录打开具体视频，确认定位、播放/暂停/拖动、失败提示与重试及权限允许时的下一节入口。播放约 10 秒后暂停、返回首页，点击“继续学习”应直达同一视频并恢复接近暂停处；仅有旧版课程记录时应退回课程详情。
3. 试卷列表与练习：检查筛选结果；确认审核禁用试卷不可进入练习。本地两卷应显示“暂无解析”：源数据仅有作答说明，说明应在答题前显示，不能在反馈或复盘中冒充答案解析。进入本地听力样本逐题播放音频（8 题、7 个文件），检查扬声器图标在 iPhone 12/13 Pro 模拟器上的形状、约 44px 点击区域、播放时高亮及切题时停止、播放失败重试；再检查选择题/填空题反馈、完成复盘、退出重进后的进度恢复，以及题库加载错误和重试。模拟器能出声不等同于真机验收。
4. 词典：分别用俄语和中文搜索，打开结果详情，检查来源/教材词汇信息、释义和例句；测试一条有缓存的教材词音频播放/停止及缺音频降级，验证搜索错误、无结果及详情缺失状态。
5. 异常与空状态：对首页、课程详情、试卷/练习、词典搜索/详情触发适用的网络错误、空结果或缺失内容状态，确认提示可理解且有可用恢复入口。
6. 每项保存截图并在结果记录中标注页面、操作、通过/失败、日期和工具版本；未实际操作的项目保持“未验收”。

## 异常和回归

- 关闭媒体服务后，页面展示明确错误和“重新加载”，不崩溃。
- 题库缺答案题目不出现；缺解析题目仍可作答但不显示虚假解析。
- 选择题答案越界的题目不出现；填空题不应被错误渲染为空选项列表。
- 个人中心的订单、设置、声明和客服入口可打开占位页。
- 真机调试使用开发机局域网地址，不使用手机上的 `127.0.0.1`。

## 结果记录

每次验收至少记录日期、开发者工具版本、是否启动媒体/内容服务、通过或失败的步骤及错误截图。以下结果必须单独标记为“未验收”，不能用静态门禁替代：真实视频渲染、真机网络、HTTPS 合法域名、生产接口、考试音频和登录后的个人数据链路。

完成后运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check_phase1.ps1`，并确认服务已停止、`config.js` 未留下局域网或生产地址。
