## 接入原则

- 当前只登记来源，不复制二进制文件，不改变 Android 仓库。
- 字母音频可在本地测试阶段建立“字母 → 音频”演示映射；正式接入前须确认授权、中文用户体验和微信音频格式/域名要求。
- `swap_snow` 音效和 `example.wav` 不与题库音频自动关联，避免因文件名或路径相似产生错误内容。
- 题库现有音频仍以题库记录为准；相对路径必须由媒体服务或生产 HTTPS 域名解析后再进行真机播放验收。
