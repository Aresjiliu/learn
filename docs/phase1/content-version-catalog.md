## 离线原始资产

`data/remote_7500km/` 保存脱敏后的本地导出压缩文件，用于重新生成样本、质量分析和映射审核。原始导出不应被小程序运行时代码直接引用，也不应上传预览或生产包。

## 版本与放行规则

- `.json` 是离线源数据；`.js` 是微信运行时模块，两者必须通过 `scripts/test_runtime_samples.js` 保持一致。
- 题库只有存在标准答案且选项有效时才进入练习样本；解析缺失只能标记为 `practice-only`。
- 教材词汇匹配分为精确、规范化、词形回溯和人工审核；人工审核记录全部批准前不得进入生产映射。
- 内容 API 和媒体服务当前均为本地只读联调；`enableRemoteWrites=false` 保持不变。
