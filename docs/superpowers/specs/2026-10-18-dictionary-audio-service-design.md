# 词典教材发音接入设计

## 目标与方案

把已审计的教材发音接到完整词典搜索、详情与媒体请求。继续使用现有稳定词条 ID，不让页面按原词猜文件名。比较直接复用旧媒体地址、客户端打包映射和服务端独立白名单：选择第三种，避免旧 HTTP 地址进入发布包，也不增加小程序包体。

## 数据流与边界

离线生成器重新运行资产审计，读取候选文件的受限字节、核对 SHA-256 后完整解码；解码失败、无声、过长、文件改变均不进入目录。目录保留词条 ID、原词、教材来源 ID、文件校验和与解码参数，写入忽略目录。目录类型明确为 development catalog，`publicationReady=false`；不将来源匹配冒称语义听审或生产放行。

服务仅在显式开发音频开关、目录、媒体根目录与回环 HTTP 基址均配置时加载目录；默认无音频。加载时核对词典索引 SHA-256 与目录结构。搜索/详情按 ID 和原词一致性补充 `audio_url`、`audioSource=textbook`、`audioDevelopmentOnly=true`，元数据版本加入音频目录版本。不存在、目录外、超限或校验失败的文件不返回播放地址，媒体接口只接受白名单文件。

媒体响应使用已校验的内存字节，避免校验后重新打开路径的内容竞态。单字音频上限 2 MiB；复用本地媒体服务器现有单 Range 解析，支持 GET/HEAD、206、416 和 Content-Range。未配置目录时不影响原有只读词典，媒体返回 404。生产 HTTPS 域名与发布白名单留作独立部署验收，不复用开发目录冒充上线。

音频模式启动时，将索引流式复制到服务私有临时目录，对同一批复制字节计算 SHA 并与目录校验；查询服务和音频都使用该私有只读批次，不再查询可变化的原始索引。原始文件无论改写、替换或恢复时间戳，都不能混入运行中的批次。切换批次必须重启并重新核验目录；生命周期退出清理约 478MB 临时副本。尝试过时间戳/Windows ChangeTime 检查，但重复回归发现粒度边界不可靠，已撤回，不作为一致性保障。私有目录仅供服务自身使用，管理员篡改其内部文件不属于公开 API 的安全边界。

## 小程序与验证

保留原生播放器和生命周期保护；使用可访问的扬声器图标按钮，标注“教材发音 · 本地验证”，播放失败提供可见重试，不覆盖词条内容。沿用 WXML/WXSS、四空格、ES2018，不增加 npm 运行依赖。

先测试目录默认关闭、源索引不匹配、ID/文件名/文件哈希、缺失与篡改、搜索和详情 URL 一致、Range、HEAD、未知文件 404，再运行真实目录生成、HTTP 烟测、页面行为与完整回归。开发者工具及 iOS/Android 实播仍需单独证据；CLI 自动化成功不等于页面或真机验收。
