# 俄语7500小程序主链路 UI 改版设计

## 1. 目标与范围

当前首页能渲染本地样本，但视觉像测试页面，课程、视频、题库和词典入口的状态表达不统一。本次改版采用“教材/考试型”视觉方向，首轮只覆盖首页、课程详情、视频播放、题库入口/练习和词典搜索/详情；优先完成“首页 → 课程详情 → 免费试听/关联词汇”主链路。

本次不更换原生小程序技术路线，不新增 UI 框架，不修改生产数据库，不开启远程写入，不把本地样本伪装成正式内容。

## 2. 视觉与信息架构

- 使用白色内容卡片、浅灰背景、深蓝灰正文、蓝色主操作和橙色考试提示；红色仅表示错误。
- 减少无业务含义的大 Banner，首屏优先展示搜索、继续学习、教材课程和考级入口。
- 统一页面边距、标题层级、按钮高度、卡片间距、圆角、阴影和状态标签。
- 本地样本显示“本地演示/免费演示”；待接入、审核中、失败和空数据分别显示独立状态。

## 3. 页面设计

### 首页

搜索作为第一入口；提供词典快捷入口和学习入口。课程区域按教材课程、考级题库和分类筛选组织。课程卡片显示封面、名称、词汇/章节信息和内容状态，不显示误导性的购买语义。继续学习卡片仅在存在真实本地进度时显示。

### 课程详情

按“课程身份 → 学习入口 → 章节目录 → 关联词汇”排列。展示稳定比例封面、教材来源、词汇/章节统计、试听或继续学习按钮。目录显示章节、时长、试听、锁定和进度；词汇区显示总数、已匹配、待复核、缺释义，并保留词典跳转。

### 视频播放

播放器保持 16:9；下方显示课程、章节、标题和进度。上一节/下一节遵循权限和媒体地址规则。播放失败、媒体待接入和锁定状态分开表达，错误时保留章节列表和重试入口。

### 题库与词典

试卷列表展示类型、题量、解析/音频状态；审核中试卷不可进入练习。练习页区分选择题、填空题、音频状态和完成复盘。词典搜索/详情区分主词典、教材词、待复核、无结果、失败和音频待接入状态。

## 4. 数据与实现边界

继续复用 `services/course.js`、`services/content.js`、内容 API 适配层、视频权限判断、本地进度服务和现有只读配置。页面只消费规范化数据，不直接依赖原始导出。`enableRemoteWrites=false` 保持不变；`enableContentApi`、媒体和音频开关按现有本地验收流程使用。

## 5. 验收标准

- 五类页面使用统一视觉语言，首页主链路可理解、可操作。
- 每个可点击入口都有实际动作或清晰不可用原因。
- 本地样本、生产内容、待审核和媒体待接入状态不混淆。
- 原有适配、权限、进度、题库质量和写入安全测试全部通过。
- 微信开发者工具逐页验收仍单独记录；代码门禁通过不等同于真机发布通过。
