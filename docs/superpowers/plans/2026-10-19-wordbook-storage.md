# 生词本存储切片

依据已批准的轻量词典规格，先交付独立服务，不新增假收藏按钮，不改变现有搜索、发音和课程权限。

## 数据契约

- `createWordbook(storage, now)` 注入同步 `read/write` 与时钟；页面后续负责微信存储适配。
- 新存储为 `{version: 1, records: [...]}`。主词典使用完整 `dict:旧ID:摘要`，同形词不按词头合并；教材未匹配词以教材集合 ID 和来源行 ID 组合身份，不自动映射主词典。
- 保存离线摘要：词头、简明释义、来源身份、首次保存时间。不保存账号、访问令牌或媒体 URL；不宣称完整词典离线可用。
- 重复加入幂等，保留首次保存时间；删除不存在的记录不写入。返回值、防御性拷贝和存储写入对象互相隔离。
- 缺省存储为空；读取失败明确报错。当前v1损坏记录只读保留，暴露仍符合v1契约的记录与阻断原因；未知版本完全不解释记录，仅暴露阻断原因并保留原存储，不向用户宣称真实词数为0，不静默清空或覆盖。当前没有已发布词本旧格式，不虚构迁移；未来迁移须另加测试。
- 写入成功后才改变内存；容量不足沿用存储错误，旧数据不变，不按数量静默淘汰。摘要字段设明确长度上限，超限拒绝而不截断。
