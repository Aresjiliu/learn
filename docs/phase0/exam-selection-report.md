# 题库筛选报告

机器结果见 `exam-selection-report.json`。

筛选规则：

- 题干和答案完整的题目进入基础练习；有选项时答案必须对应非空选项，无选项时按填空题处理。
- 解析缺失不阻断基础练习，但不显示“含解析”。
- 试卷至少 5 道题且可答题完整率不低于 80%，标记为 `practice-ready`。
- 解析完整率不低于 80%，标记为 `analysis-ready`。

本次结果：308 份有题试卷中，279 份可进入基础练习，204 份解析相对完整；基础练习候选题目 12,304 道。运行时适配层与离线筛选脚本采用同一答案有效性规则。

音频单独统计：26 份试卷包含原文音频字段，共 455 道题具备音频地址；原文表共 616 条记录、374 个唯一音频字段，当前全部是相对 `.mp3` 路径，没有 HTTPS/HTTP 绝对地址。这只证明数据字段存在，不代表地址已在小程序合法域名、HTTPS 和真机环境中可播放，因此音频入口仍需逐项验证。

报告 JSON 另外统计全部有题试卷中“可答题”的选择题与填空题数量；它们与 `selectedQuestionCount` 的放行候选题口径不同，便于分别安排选项质量、文本判分和后续解析审核。

空题干也单独统计为 `blankQuestionCount`，不会进入练习候选；当前报告中的该数量应作为题库清洗和人工复核的输入，而不是可练习题数量。

含 Unicode 替换字符 `�` 的题干、答案、选项或解析视为编码损坏，按 `corruptTextCount` 统计；损坏解析不计入“解析完整”，避免乱码直接展示。

补充质检：当前 277 道文本题进入练习候选，未发现“无/暂无/待定”等明显占位答案；另有 1 道答案长度超过 80 个字符，已从练习候选中暂时排除并保留在报告中，首发前需人工确认是否确实需要整句作答。该指标由 `select_exam_content.py` 写入报告的 `summary.longTextAnswerCount` 和各试卷的 `longTextAnswerCount`。
