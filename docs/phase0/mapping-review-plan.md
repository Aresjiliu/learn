# 教材词汇映射复核计划

`mapping-review-plan.json` 是从独立复核队列生成的排序视图，不会修改原始 CSV、数据库或运行时映射。每条记录仍需人工确认后，才能进入后续独立映射表。

## 分层策略

1. `first-wave`：当前首轮产品验证课程《东方教材大学俄语3》和《俄语专业大纲综合》。优先处理有教材释义的未匹配词；唯一原型的词形映射可在审核后进入学习内容。
2. `second-wave`：存在较多高优先级复核项的其他教材。先核对多原型词形，再按课程入口和使用频次处理未匹配词。
3. `later`：暂不影响课程展示的低优先级记录。继续展示教材原词和教材释义，不承诺主词典音频或补充释义。

## 放行规则

- `exact`、`relaxed`：可自动建立候选映射，但保留教材原词和匹配层级。
- `wordForm`：只有唯一原型、词义和词性可解释时，审核后放行。
- `unmatched`：不自动猜测；教材已有释义时可展示教材内容，但词典能力标记为待补充。
- 所有人工结果写入独立映射表，至少包含教材词、教材标识、主词典 ID、匹配层级、审核状态和备注。

本计划的当前排序只用于节省审核成本，不等同于内容已审核或已达到生产发布标准。
