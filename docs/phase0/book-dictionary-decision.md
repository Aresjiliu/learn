# 教材词汇与主词典处理决策

数据来源为本地已校验导出，报告见 `book-dictionary-comparison.json`。本次统计按标准化词形去重，不代表每本教材的词条总行数。

## 当前结果

| 层级 | 数量 | 处理策略 |
|---|---:|---|
| 精确匹配 | 13,601 | 可自动建立映射，保留教材释义和重音；主词典补充音频/来源 |
| ё/е 等价匹配 | 36 | 可自动映射，但展示教材原词并记录 `relaxed` |
| 词形回溯 | 331 | 进入可学习映射，必须记录原型和来源，不覆盖教材释义 |
| 未匹配 | 1,367 | 不删除、不强行合并，进入人工复核 |

总体覆盖率为 91.0858%。产品首版只自动放行前三类；未匹配词可继续展示教材原词，但不依赖主词典音频或释义。

## 按教材的优先级

当前本地课程样本中的《东方教材大学俄语3》有 1,247 个词，覆盖率 95.9102%；《俄语专业大纲综合》有 7,816 个词，覆盖率 99.9744%，均适合优先用于首轮产品验证。全量未匹配最多的教材为“走遍俄罗斯-第三册”（299 个）、“黑大俄语2新版”（184 个）和“黑大俄语第一册”（156 个），暂不应直接承诺完整词典覆盖。

报告现已提供 `byBook` 分组统计，包括去重词数、各匹配层级、释义缺失数、覆盖率和未匹配样本；后续人工复核按未匹配数量与首发课程优先级排序。

完整复核队列由 `scripts/export_mapping_review_queue.py` 生成，输出为 `mapping-review-queue.json`。本次队列共 1,781 条教材—词形记录，其中 1,610 条为主词典未匹配，171 条为多原型词形歧义；队列保留 `reviewStatus=pending`，后续审核结果应写入独立映射表，不回写原始导出。

队列的执行顺序见 `mapping-review-plan.json` 和 `mapping-review-plan.md`。当前首发样本教材共 60 条待复核记录，优先处理这些记录不会改变主词典或原始教材数据。

## 复核优先级

1. 教材中有中文释义、但未匹配主词典的高频词。
2. 词形回溯存在多个原型候选的词。
3. 只有主词典匹配、教材释义为空的词。
4. 词形、重音或连字符异常的词。

人工处理结果应形成独立映射表，至少包含教材词、主词典 ID、映射层级、审核状态和审核备注；不要直接修改原始导出或生产表。

## 验收规则

- `exact` 和 `relaxed` 可进入自动映射候选集。
- `wordForm` 只有在原型唯一且可解释时进入学习映射。
- `unmatched` 保持可见并标记“待补充”，不得因缺失主词典数据而丢失教材内容。
