# 阶段 0：迁移白名单与禁止项

## P0：首批可迁移内容

- 俄语词条、词性、释义、变形、词根和词频。
- 例句及其中文/俄文文本。
- 教材、课程分类、课程词汇和学习顺序。
- 试卷分类、题目、选项、答案和解析（项目所有者已确认可用于本项目；缺失答案的题目不进入基础练习）。
- 音频和图片的引用地址，迁移到受控 CDN 后再开放。

## P1：验证后迁移

- 专业词汇和行业词库。
- 用户历史学习进度、收藏、错题和考试成绩。
- 学习计划、复习会话和统计结果。
- 购买记录和订阅权益。

## 暂不迁移

- 生产环境账号密码、JWT、签名密钥和测试账号。
- 未完成脱敏的用户行为明细和未确认来源的第三方数据。
- 旧 API 的生产域名、内部管理接口和数据库连接信息。
- 直接把完整生产库复制到小程序或 AI 服务。

## 迁移前验收

1. 每张源表完成字段映射、字符集、主键和去重规则。
2. 内容抽样通过：俄语、中文、词形、例句、音频链接均可正常展示。
3. 用户迁移采用不可逆脱敏、显式授权和可回滚批次。
4. 迁移脚本支持 dry-run、行数校验、失败重试和审计日志。
5. 旧数据只读保留，直到新系统完成对账和业务验收。
