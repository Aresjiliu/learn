## 建议审核顺序

1. 先处理 7 条多原型记录，补齐词性、释义和上下文后再决定 `approved` 或 `needs-more-data`。
2. 再处理有明确教材释义的单词，优先确认主词典是否缺少专名、地名或教材专有短语。
3. 短语和电影/地名等专名默认作为“教材词汇”展示，不强行拆分为主词典单词；只有存在可靠独立词典条目时才建立映射。

所有批准结果仍须填写 `selectedPrototype`、`dictionaryId` 和 `reviewNote`，并通过 `scripts/check_mapping_review.py` 后才可进入独立映射表。
