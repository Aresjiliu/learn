# 小程序路线评估任务

## Task 1：建立接口与字段对照

**范围：** 对照 `7500km-android`、`weixin`、`Russion1` 的课程、词典、登录和媒体字段。

**验收：** 输出来源、请求条件、响应字段、鉴权方式、是否可被小程序直接访问；不记录密钥值。

## Task 2：完成课程试听垂直切片设计

**范围：** 以 `learn` 的课程首页、详情页和视频页为基线，定义免费首节、词汇关联和错误状态。

**验收：** 真机可验证的页面清单、数据适配点、媒体地址要求和退出条件。

## Task 3：验证后端路线

**比较：** 旧 API 直连、BFF 适配层、独立内容服务。

**验收：** 以接口成功率、字段覆盖、部署合规、内容映射成本和后续迁移成本做决策；路线确定前不开发新 API。

## Task 4：实现首个切片

**依赖：** Task 1-3。

**验收：** 课程列表、详情、公开媒体、关联词汇在微信开发者工具和真机可用；网络失败、空数据和资源失效有提示。
