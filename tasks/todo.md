# 生产化任务清单

每项均须先验证当前行为，按测试先行实施；“完成”以代码、自动检查和指定人工证据共同判定。`S/M` 表示预计改动规模，不是工期承诺。

## A. 内容与词典

- [ ] **A1 内容服务部署基线（M）**。依赖：无。范围：`scripts/serve_content_api.py`、部署配置和新服务测试。验收：把开发用 `http.server` 与生产服务分离；HTTPS 环境返回内容版本、健康状态和分页词典；只读、限流与错误日志可验证。验证：API 契约、部署烟测和断网测试。
- [ ] **A2 搜索索引与结果质量（M）**。依赖：A1。范围：词典索引生成/查询、`services/content-api.js`。验收：俄语精确/前缀、`е/ё`、词形及中文释义查询均有可解释排序；分页稳定；记录 16.6 万词规模下的延迟。验证：真实导出抽样、边界测试、性能记录。
- [ ] **A3 发音资源审计与服务（M）**。依赖：A1。范围：音频清单、`services/media/audio.js`、媒体服务。验收：只为已核验文件返回可播放 URL；首册教材映射和主词典发音分别统计；缺失、404、格式错误均可恢复。验证：HTTP Range、播放器与 iOS/Android 实播。
- [ ] **A4 词典搜索/详情 UI（M）**。依赖：A2、A3。范围：`pages/dictionary/search/`、`pages/dictionary/detail/`、共享视觉令牌。验收：词形、分义项、来源、发音、历史、错误和空状态可见；长俄语词不溢出；点击目标可用。验证：组件/页面测试与 320–430px 截图。

## B. 学习闭环

- [ ] **B1 本地生词本（M）**。依赖：A2、A4。范围：新生词本服务/页面、词典和课程词入口。验收：按稳定词条 ID 添加/删除、去重、记录来源与时间；断网可用；可导出非个人敏感学习数据。验证：存储迁移、重复添加、容量与页面测试。
- [ ] **B2 到期复习与错题回流（M）**。依赖：B1。范围：复习调度、练习进度及复盘页。验收：答对/答错改变下次复习日期，错题可入复练；题库审核门禁不被绕过。验证：时间边界、重启恢复、俄语答案归一化测试。
- [ ] **B3 账号与同步（M）**。依赖：B1、B2。范围：登录服务和学习事件同步。验收：本机数据与账号绑定规则明确；跨设备合并不丢词或重复答题；个人信息与内容分析分离。验证：冲突、离线重试、退出登录与隐私测试。
- [ ] **B4 课程/题库内容发布切片（M）**。依赖：A1。范围：课程与试卷发布清单、服务端目录。验收：只发布审核通过的媒体和题目；测试视频与真实课程明显区分；试听、已购和不可用状态一致。验证：质量报告、权限及目录到播放端到端测试。

## C. UI 与交易

- [ ] **C1 统一设计与真机回归（M）**。依赖：A4、B4。范围：首页、课程、词典、练习、我的及组件。验收：排版、图标、加载/空/错误、底部安全区统一；iPhone 12/13 Pro、窄屏和 Android 有截图与操作记录。验证：视觉对照、无障碍标签、导航和弱网回归。
- [ ] **C2 商品与订单状态机（M）**。依赖：B4；支付资质确认。范围：服务端商品/订单、课程页和订单页。验收：服务端锁价、幂等建单、取消与过期状态；无支付时不发权益。验证：重复点击、篡改金额和状态迁移测试。
- [ ] **C3 微信支付与权益（M）**。依赖：C2、商户号/AppID 绑定。范围：官方支付 SDK、回调/查单、权益与媒体授权。验收：验签、金额和订单号核对、回调幂等、退款撤权、查单兜底；小程序回调不能单独开课。验证：沙箱/受控实付、回调重放、退款与越权测试。
- [ ] **C4 发布门禁（M）**。依赖：A1–C3。范围：环境配置、自动化、监控、备份和发布文档。验收：无本地 HTTP/测试资源/密钥进入发布包；关键主链路真机通过；可监测播放/支付错误并能回滚。验证：发布包审计、恢复演练、远端提交核对。

## 检查点

- [ ] A1–A4：词典服务、真实查询和发音在开发者工具及真机均通过。
- [ ] B1–B4：一名用户可从课程词/查词进入生词本、复习并保留进度；题目质量门禁通过。
- [ ] C1–C4：设计、支付、隐私与发布证据齐全；此前不得将综合目标标记完成。
